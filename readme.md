# Artrómeda

Artrómeda es una aplicación web desarrollada para la gestión y exhibición de obras de arte. La plataforma permite a los usuarios explorar una galería virtual, conocer información detallada sobre cada obra y realizar compras de manera sencilla mediante un carrito de compras integrado.

Este proyecto fue desarrollado como parte de mi proceso de formación en Análisis y Desarrollo de Software, aplicando conocimientos de programación web, bases de datos y diseño de interfaces.

## Proyecto en línea

**Demo:** https://artromeda.infinityfreeapp.com/

---

## ✨ Funcionalidades

* Visualización de obras de arte en una galería virtual.
* Consulta de información detallada de cada obra.
* Carrito de compras para la gestión de pedidos.
* Registro e inicio de sesión de usuarios.
* Administración de perfiles de usuario.
* Panel de administración para la gestión de obras.
* Generación de facturas en formato PDF.
* Gestión de imágenes de obras y perfiles.
* Diseño responsivo adaptable a diferentes dispositivos.
